# Tutorial

## Testing your first mod!

In Exam Editor, ensure your mod is enabled. 

- In the Menu UI (the default), the mod is enabled if it has the Equipped `E` on it. If it does not, simply click on it.

- In the Legacy UI, the mod is enabled if its `On` check mark is checked. If it is not, click on the box to check it.

Now click the deploy button, and press `Yes` to the disclaimer.

- In the Menu UI, this button is the right-facing cyan arrow inside the list of mods.

- In the Legacy UI, this button is the rocket with a microSD card image.

Press `OK` to the confirmation dialogue.

Open Azahar and launch the game, and go to an area where your mod would be visible.

- For the mod we just made this can either be:
  
  - Starting a new save file, skipping all cutscenes until the Phantom Ursula fight begins.
  
  - Loading a Sora save file.
  
  - Loading a Riku save file and dropping to Sora.

You should now see that Sora's keyblade is the Kingdom Key D.

***Congrats!***

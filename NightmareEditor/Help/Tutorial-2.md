# Tutorial

## Making your first mod! (2)

### Getting the textures

Inside the game files, Riku has a version of the Kingdom Key D that remains unused. We will be extracting the textures to put onto the Kingdom Key. The steps from here on out will be numbered so that you don't lose your place.

1. Click the large `+` button to add a file.
   
   - From your RomFS dump, find and select `chara_wep.rbin`.
   
   - Wait for the file to finish extracting. It may take a while.

2. Click on `chara_wep.rbin` inside the editor.
   
   - Wait for the file to finish loading. It may take a bit.

3. In the second column, find and click on `w_ri010.pmo`
   
   - You can search for files using the text box at the top of the second column.
   - This will load the first texture in the file.

4. Right-click the texture and select `Save Embedded Texture`.
   
   - You'll notice there are two views, Embedded and Linked textures.
   - Right now, they are the same, but it is important to notice. You can right-click on either.
   - Save the texture to a location on your computer.

5. In the third column, click `w_ri010_01.ctt`.

6. Right-click the texture and select `Save Embedded Texture`.
   
   - Same as Step 4.

Great! Now we have the textures we need.

***You've learned how to extract textures from the game files!*** Not too hard, right?
